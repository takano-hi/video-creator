本の感想をミルクボーイ風に紹介する動画を作成します。

## 手順

### 1. 情報収集

`$ARGUMENTS` が空の場合は、以下を確認してください：
- 紹介する本のタイトルと著者
- あらすじ・テーマ・主人公の特徴
- 本のユニークな魅力（笑える点・泣ける点・驚く点など）
- 著者や受賞歴などの補足情報

### 2. ミルクボーイ風スクリプト作成

以下のフォーマットでスクリプトを組み立ててください。

**登場人物：**
- **ずんだもん**（speaker ID: 3）→ 駒場役：おかんが読んだ本のヒントを出す側
- **四国めたん**（speaker ID: 2）→ 内海役：ヒントから本を推理・断定する側

**ミルクボーイの型：**
1. ずんだもん：「うちのおかんがな、最近読んだ本が気に入っとって、タイトルが思い出せんらしくてな」
2. 四国めたん：「どんな本やったん」
3. ずんだもん：（本の特徴①②を挙げる）
4. 四国めたん：「〜！それはもう絶対『○○』やないか！〜（理由）〜『○○』で決まりやないか」
5. ずんだもん：「そうそう。でもな、〜（特徴③）らしいねん」
6. 四国めたん：「そんなん〜やがな！〜（展開）〜ますます『○○』やないか」
7. ずんだもん：「ほな確定やな。でもな、一個だけわからんとこがあってな」
8. 四国めたん：「なんやねん」
9. ずんだもん：（一見矛盾しそうな特徴）
10. 四国めたん：「ほな『○○』やないか！〜（逆手に取る論理展開）〜真骨頂やないか」
11. ずんだもん：「ほなそれで確定やな！でもな、もう一個だけな」
12. 四国めたん：「まだあるんかい」
13. ずんだもん：（著者情報や受賞歴などのトリビア）
14. 四国めたん：「それも『○○』やないか！〜（洒落た締め）〜以外に何があるねん！」
15. ずんだもん：「ほな確定やな！」
16. 四国めたん：「『○○』！みなさんも、ぜひ読んでみてください！」

**字幕の改行ルール：**
動画の横幅の制約により、字幕は **1行あたり最大23文字程度** しか表示できません。セリフを `generate_subtitle_csv` に渡す際は、意味の区切りの良い位置に `{br}` を挿入し、1行が23文字を超えないようにしてください。

### 3. 音声生成

**VOICEVOX への文字列について：**
VOICEVOX は漢字を読み違えることがあります。`generate_audio` に渡す text は以下のルールで調整してください：

- 読み違いやすい漢字はひらがなに置き換える（例：「真骨頂」→「しんこっちょう」、「受賞」→「じゅしょう」）
- 固有名詞・タイトル・人名は特に注意し、不安な場合はひらがな・カタカナに変換する
- `{br}` は音声テキストには **含めない**（字幕テキスト専用）
- 1人のスピーカーの発言でも、長い場合は **複数の items に分割** してください（目安：句読点・接続詞など意味の区切りで分割）

`generate_audio` ツールを呼び出してください：

```json
{
  "items": [
    {"speaker": 3 または 2, "text": "セリフ（{br}なし・読み仮名調整済み）"},
    ...
  ]
}
```

### 4. cover.png を移動

`generate_audio` の戻り値からディレクトリパスを取得し、`/Users/takano-h/work/video-subtitle/tmp/cover.png` を生成ディレクトリにコピーしてください：

```bash
cp /Users/takano-h/work/video-subtitle/tmp/cover.png <生成ディレクトリ>/cover.png
```

**ファイルが見つからない場合は自分で探しに行かず、ユーザーに `cover.png` の場所を確認してください。**

### 5. 字幕 CSV 生成

`generate_subtitle_csv` ツールを呼び出してください：

```json
{
  "directory": "<generate_audioが返したディレクトリ>",
  "lines": [
    {"speaker": "ずんだもん" または "四国めたん", "text": "字幕テキスト（{br}あり）"},
    ...
  ]
}
```

音声ファイルと **同じ順番・同じ行数** で渡してください。音声を分割した場合は、字幕も同じ分割単位で対応する行を追加してください。

### 6. 動画生成

`generate_video` ツールを呼び出してください：

```json
{
  "directory": "<generate_audioが返したディレクトリ>"
}
```

### 7. 完了報告

生成された `video.mp4` のパスをユーザーに伝えてください。
